# Maji Mazuri Children's Hospital – HMIS

Starter hospital management information system for a paediatric hospital. Plain HTML/CSS/JS, no build step.

## Run
Open the folder in VS Code and either open `index.html` in a browser or use the **Live Server** extension.

## Structure
- `index.html` – layout and navigation
- `css/style.css` – blue / green / white theme (colours are variables at the top of the file)
- `js/app.js` – data, views, forms. Data is saved in the browser's localStorage (replace `load()`/`save()` with API calls for a real backend)

## Included
Dashboard, child registration with age/weight/allergies/guardian, ward census, appointments, immunization tracker (Kenya schedule).

## Next ideas
Triage & vitals, growth charts (WHO z-scores), paediatric dose calculator (mg/kg), pharmacy, lab, billing/NHIF, user login and roles, a real backend and database.
